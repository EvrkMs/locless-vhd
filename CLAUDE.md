# locless-vhd

Сервер образов Windows для компьютерного клуба (Go): клиент грузится из VHDX на скрытом
разделе, сеанс сбрасывается на каждой загрузке. Форк locless-disk.

## Правила

- **Go, тесты, node — только в WSL-дистрибутиве `claude`**:
  `wsl -d claude -e bash -lc "cd /mnt/c/locless-vhd && go test -race ./..."`.
  Этот Windows — сервер CCBoot, на него ничего не ставить. `python` на Windows есть, а
  `python3` — заглушка магазина; для правок файлов брать Edit, а не скрипты.
- Агент под Windows проверять `GOOS=windows go vet ./agent/`: часть кода только `_windows.go`.
- `gofmt -l` по рабочей копии выдаёт ложные срабатывания из-за CRLF. Проверять файл так:
  `tr -d '\r' < файл | gofmt -d`.
- Скрипты PowerShell — только ASCII: Windows PowerShell 5.1 читает файл без BOM в ANSI.
  Для `build.ps1` это держит тест `TestScriptIsASCII`.
- Тексты для оператора (панель, экран агента, ошибки) — по-русски; комментарии и сообщения
  коммитов — по-английски.
- Коммитить можно, **пушить только когда пользователь скажет** («запушить»).
- Что меняет систему этого сервера (DISM mount, reagentc, разделы) — только во временных
  папках проекта (`data/`) и с откатом; системные настройки не трогать.
